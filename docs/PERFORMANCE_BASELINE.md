## Повторение

```sh
GALLIUM_DRIVER=d3d12 MESA_D3D12_DEFAULT_ADAPTER_NAME=NVIDIA MODULE_TEST_SECONDS=10 npm run test:fps -- --headed
```

Запускать с доступом к графической сессии и GPU этого ПК. В текущем sandbox GPU недоступна, поэтому замер выполнен вне sandbox. Переменные выбирают установленный WSL-драйвер только для процесса. Без них диагностический Chromium выбрал программный llvmpipe, WebGL не создался. Не включать такой результат в аппаратную базовую линию.

Перед сравнением проверить renderer, версию браузера, размеры canvas, включённые модули и маршруты. Сохранить одинаковые питание и графическую сессию, завершить параллельные сборки и тяжёлые задачи. Запуск открывает отдельное окно и не использует личный профиль браузера.

## Пакеты дорожных поверхностей

В object-rendering добавлен явный пакетный путь для static с одной прямоугольной деталью на LOD и заданным opaque-материалом. World использует его для road/sidewalk/curb. Группировка по ячейке 128, идентичности материала и LOD; индивидуальные дистанции сохранены. До 155 экземпляров поверхностей и до 20 пакетов на обычном контрольном маршруте (максимумы до frustum culling, не фактические draw calls).

Исправлены две ошибки реализации: thin-instance атрибуты хранятся на Geometry, поэтому каждый пакет обязан вызвать makeGeometryUnique до записи буферов; при переиспользовании буфера сначала задаётся новое thinInstanceCount, затем вызывается thinInstanceBufferUpdated, иначе загрузка ограничена старым числом экземпляров. Добавлены регрессионные проверки изоляции Geometry/атрибутов, удаления соседнего пакета и изменения состава 2→1→2. Буферы переиспользуются и растут по необходимости, общая AABB пересчитывается только при изменении состава/матриц. Аппаратный снимок после исправлений показывает дороги и тротуары на прежних местах. Замеры промежуточных вариантов со сломанным изображением не считать результатом оптимизации.

Финальный обычный прогон `2026-11-13T02:14:46.670Z`: world **58.64 FPS**, P95 **20.5 мс**, те же RTX 3050 / WSL D3D12, Chromium 145 с окном, 1280×720, весь реестр и прежний маршрут. Обычный отчёт сохранён как artifacts/fps-report.json.
