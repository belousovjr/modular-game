# Базовое освещение (`lighting`)

Клиентский визуальный модуль категории «Окружение», без зависимостей. Включён в стартовый набор, отключается независимо. Публичное определение — lightingModule из index.ts; публичный тип — LightingSettings. light.ts и panel.tsx приватные. Симуляцию и authority не меняет, теневые карты не создаёт.

Создаёт ровно два источника: HemisphericLight lighting/ambient и DirectionalLight lighting/sun. Единственная настройка LightingSettings — hour, конечное число от 0 включительно до 24 исключительно, дробная часть задаёт минуты/секунды. По умолчанию 14:00. API getSettings(), setSettings(next), subscribe(listener) сохраняется; старые ручные azimuth/elevation/intensity/color удалены. Снимки неизменяемы, некорректное время отклоняется до изменения источников. После остановки изменение и подписка отклоняются.

По времени вычисляется непрерывная фиксированная траектория солнца: восход 06:00 со стороны +X, полдень над южной стороной +Z, закат 18:00 на -X. Направление лучей нормировано. На горизонте цвет тёплый, в полдень светлее и нейтральнее; diffuse/specular согласованы. После заката направленный источник имеет нулевую интенсивность. Рассеянная подсветка плавно переходит от дневной к слабой голубоватой ночной, включая groundColor. Переход через полночь непрерывен. Это художественная модель без даты, широты, сезонов, облаков, лунного диска и атмосферного неба; физическую точность для Чикаго не заявлять. Эмиссия материалов остаётся видна ночью.

Панель через core.panels.register('lighting', 'Освещение', …) содержит время HH:MM, один Radix Slider с шагом 1 минута и кнопки «Утро» (08:00), «День» (12:00), «Вечер» (18:00), «Ночь» (00:00). React подписан через useSyncExternalStore; рендер-цикл UI не обновляет. Закрытие окна сохраняет свет, пересоздание сцены возвращает 14:00. Нет сохранения пресетов, записи времени в storage, экспорта или undo/redo.

Время выбирается вручную. Автоматического хода суток и чтения Date/performance/timers нет. При появлении игрового времени его задаёт authority, lighting только отображает присланное значение; локальная настройка сейчас не является временем общей сессии.

Оба источника немедленно регистрируются в scope. Там же регистрируются очистка Observable и удаление панели. При остановке и частичном неудачном setup ресурсы освобождаются; повторное включение создаёт новую пару с начальными настройками. Core источников не создаёт. Сценария ▶ нет: модуль не добавляет тестовый контент, проверяется в существующих обзорах ground/beacon/world.

Проверки: tests/lighting.test.ts (Node/NullEngine) — направление и единичная длина вектора, противоположные стороны утром/вечером, тёплое утро, более сильный дневной свет, отсутствие солнца ночью и слабая подсветка, непрерывность у полуночи, атомарное отклонение неверного времени, подписки и повторная очистка без дублей. Аппаратный браузер: открыть панель, выбрать день/ночь, изменить время клавиатурой, закрыть/открыть и выключить/включить модуль. Собственного сценария ▶ нет; используем существующий квартал без дополнительного контента.
