# Базовое освещение (`lighting`)

Клиентский визуальный модуль категории «Окружение», без зависимостей. Включён в стартовый набор, отключается независимо. Публичное определение — lightingModule из index.ts; публичный тип — LightingSettings. light.ts и panel.tsx приватные. Симуляцию и authority не меняет, теневые карты не создаёт.

Создаёт ровно два источника: HemisphericLight lighting/ambient и DirectionalLight lighting/sun. LightingSettings содержит hour, конечное число от 0 включительно до 24 исключительно, дробная часть задаёт минуты/секунды. По умолчанию 14:00. API getSettings(), setSettings(next), subscribe(listener) сохраняется; старые ручные azimuth/elevation/intensity/color удалены. Снимки неизменяемы, некорректное время отклоняется до изменения источников. После остановки изменение и подписка отклоняются.

По времени вычисляется непрерывная фиксированная траектория солнца: восход 06:00 со стороны +X, полдень над южной стороной +Z, закат 18:00 на -X. Направление лучей нормировано. На горизонте цвет тёплый, в полдень светлее и нейтральнее; diffuse/specular согласованы. После заката направленный источник имеет нулевую интенсивность. Рассеянная подсветка плавно переходит от дневной к слабой голубоватой ночной, включая groundColor. Переход через полночь непрерывен. Это художественная модель без даты, широты, сезонов, облаков, лунного диска и атмосферного неба; физическую точность для Чикаго не заявлять. Эмиссия материалов остаётся видна ночью.

Панель через core.panels.register('lighting', 'Освещение', …) содержит время HH:MM, Radix Slider времени с шагом 1 минута и кнопки «Утро» (08:00), «День» (12:00), «Вечер» (18:00), «Ночь» (00:00). React подписан через useSyncExternalStore; показания обновляются по подписке на часы. Закрытие окна сохраняет свет. Клиент восстанавливает час и множитель из версионированного ключа localStorage при пересоздании сцены и перезагрузке. Время суток продолжает идти с сохранённой отметки; время закрытой страницы не учитывается. Настройки не участвуют в экспорте или undo/redo.

В этой же панели Radix Slider скорости: 0× (пауза) или логарифмическая шкала 0.0625×…128×. Клиентский API getSpeed()/setSpeed(value) принимает конечный множитель 0…128. Освещение по умолчанию на паузе; atmosphere запрашивает 1× при первом запуске, если сохранённой пары нет. При 1× сутки занимают 20 минут, при 128× — около 9.4 с. Освещение получает delta от core.onFrame, группирует обновления с интервалом 50…250 мс и применяет остаток по прежней скорости при её смене. Date/performance/timers не читаются. При появлении игрового времени его задаёт authority, lighting только отображает присланное значение; локальная настройка сейчас не является временем общей сессии.

Оба источника немедленно регистрируются в scope. Там же регистрируются очистка Observable и удаление панели. При остановке и частичном неудачном setup ресурсы освобождаются; повторное включение создаёт новую пару с начальными настройками. Core источников не создаёт. Сценария ▶ нет: модуль не добавляет тестовый контент, проверяется в существующих обзорах ground/beacon/world.

Проверки: tests/lighting.test.ts (Node/NullEngine) — направление и единичная длина вектора, противоположные стороны утром/вечером, тёплое утро, более сильный дневной свет, отсутствие солнца ночью и слабая подсветка, непрерывность у полуночи, атомарное отклонение неверного времени, подписки и повторная очистка без дублей. Аппаратный браузер: открыть панель, выбрать день/ночь, изменить время клавиатурой, закрыть/открыть и выключить/включить модуль. Собственного сценария ▶ нет; используем существующий квартал без дополнительного контента.

Клиентский API getSunLight() возвращает заимствованный DirectionalLight для shadows; после остановки отклоняется. Lighting продолжает владеть источником, его направлением/интенсивностью/цветом. Shadows временно владеет положением, параметрами теневой проекции и shadowEnabled и восстанавливает их при очистке. Это клиентский Babylon-ресурс, не игровой/сетевой снимок; внешний модуль не уничтожает источник.

Поставка 14: художественная рассеянная подсветка ambient.intensity=0.2+0.45*daylight (0.2 ночью, 0.65 днём), ночные diffuse/groundColor #91a6c8/#252c3c. Это сохраняет различимость тёмных поверхностей без размножения динамических ламп; солнце ночью по-прежнему выключено. Тест требует ненулевую читаемую ночную подсветку слабее трети дневной, атомарность настроек и очистка прежние. Эмиссия плафонов не является освещением улицы; локальные пулы света и небо не добавлены в этой поставке.

Опциональный atmosphere — внешний потребитель setSettings/subscribe/getSunLight и getSpeed/setSpeed: локальная демонстрация хода суток, не игровое серверное время. Часы и ползунок доступны и без atmosphere. Временная смена часа и скорости в сценарии atmosphere оформлена через previewCycle(scope) и пропускается при локальном сохранении.
