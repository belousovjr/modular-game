# Демонстрационное освещение (`lighting`)

Клиентский визуальный модуль категории «Окружение». Создаёт один Babylon `HemisphericLight` с направлением `(0, 1, 0)` и стандартными параметрами. Зависимостей нет; включён в стартовый набор, но может быть отключён независимо от остальных модулей.

Публичное определение — `lightingModule` из `index.ts`. API экземпляра пустой. Источник света регистрируется в scope сразу после создания и удаляется при остановке модуля. На симуляцию не влияет.

Собственного тестового сценария нет: освещение участвует в обзорах сцены других модулей. В браузере проверить включение и отключение через «Применить», восстановление через сброс набора и отсутствие дублирования света после повторного применения.
