# Управление персонажем (`player-control`)

Клиентский модуль «Игра», вне стартового набора; requires characters/object-rendering/world. Включение автоматически подключает персонажа и его зависимости, стартовый набор не меняет. API экземпляра пустой, отдельного сценария ▶ нет: headless правила и отдельный сценарий находятся в characters. Полёт/плавание не реализованы.

WASD — намерения относительно камеры, Shift — бег; Space — одно намерение прыжка на нажатие (repeat игнорируется, blur очищает очередь); ПКМ — орбита штатной ArcRotateCamera, колесо — дистанция 1.5…10 м. Для движения canvas должен иметь фокус; Ctrl/Alt/Meta, текстовый UI, скрытая вкладка, blur и тестовая камера не управляют персонажем. Отпускание клавиш/blur очищают held keys, отправляется остановка, дополнительно действует authority TTL. Команды JSON отправляются через characters.send с последовательностью и tick последнего снимка, максимум одна за наблюдаемый tick и keepalive раз в 6 тиков. Меш и позиция authority напрямую не изменяются. send асинхронен, очередь принадлежит локальному адаптеру.

Камера следует за неизменяемым снимком на высоте +1.2 м. Перекрытие сферы камеры радиусом 0.2 с AABB world.collision укорачивает дистанцию, в том числе для выгруженных объектов. При освобождении обзора восстанавливается желаемая дистанция; минимальная фактическая дистанция может быть меньше пользовательского зума. Sphere/box sweep имеет skin 0.02 м; минимальная доля не должна вытолкнуть камеру за препятствие. Broad phase отсекает AABB вне X/Z коридора сегмента до выделения временных массивов. setTarget сохраняет alpha/beta/radius при перемещении героя. Это консервативный обход прямоугольных препятствий, без затухания стен/силуэтного анализа референса. Соседний chicago-test использован только как референс ощущения, не изменяется.

Прежняя свободная камера сохраняется, control отсоединяется; на остановке возвращаются её активность и управление. Камера игрока не SceneCamera, поэтому core не записывает её в localStorage. Камерные/клавиатурные/blur подписки и подключение distance source сразу принадлежат scope. Источник дистанции в режиме игрока — позиция героя. Во время core-сценариев источник явно становится тестовой камерой, ввод приостановлен; это не неявная подстановка камеры при отсутствующем герое. Core tests временно переключает activeCamera и возвращает её, player-control не перехватывает это переключение.

Проверить в браузере: включение, WASD/Shift и ПКМ/колесо, остановку у здания/фонаря, бордюр/уклон, отсутствие прохода в выгруженный collider, столкновения камеры, Ctrl+S/UI/focus/blur, запуск/остановку сценариев и возврат личной камеры, повторное переключение модуля и число ресурсов. Тяжёлые проверки последовательно, с MemoryMax=2G/MemorySwapMax=0/timeout; программный renderer не выдавать за аппаратный FPS.
