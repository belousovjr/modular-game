# Площадка (`ground`)

Клиентский визуальный модуль: плоская площадка 18 × 18 в Babylon-сцене. Зависимостей нет.

Публичное определение — `groundModule` из `index.ts`. API экземпляра: `heightAt(x, z): number`, сейчас всегда возвращает `0`. Потребитель — модуль `beacon`; при изменении API проверить его вызовы.

`heightAt` описывает демонстрационную поверхность, не авторитетную игровую геометрию. Не использовать меш как источник истины для будущей симуляции. При изменении формы площадки согласовать визуальную высоту и `heightAt`.

Категория в списке модулей: «Окружение».

Сценарий `test`: 4 секунды кругового обзора площадки с изменением высоты и дистанции, плюс 1 секунда прогрева runner. Центр камеры получает высоту через собственный `api.heightAt`.

Сценарий требует ArcRotateCamera: встроенный runner core подставляет временную орбитальную камеру, а после завершения/отмены/ошибки возвращает пользовательскую свободную камеру. Маршрут сценария от ручного управления не зависит.
