# Симуляция (`simulation`)

Опциональный клиентский адаптер headless-часов из `src/simulation/authority.ts`, включён в стартовый набор. Зависимостей нет. Core передаёт монотонную разницу времени через `onFrame`; модуль вызывает `authority.advance` до рендера. Игровой режим не нужен.

Публичное определение — `simulationModule` из `index.tsx`. API экземпляра: `snapshot(): Snapshot` — сериализуемый снимок часов. Потребитель — `beacon`; его зависимость автоматически включает симуляцию. Изменение API согласовывать с потребителями.

React-компонент `SimulationInfo` подписывается на кадры через `useEffect` с очисткой подписки. Инфо-панель через `core.panels` использует готовый `DataList` из Radix Themes и показывает секунды, tick и pendingTicks. Закрытие панели не останавливает часы. При пересоздании сцены создаётся новая authority с нуля. Правила фиксированного шага и задолженности остаются в headless-логике; DOM и Babylon туда не переносить.

Категория в списке модулей: «Системы».

Клиентский сценарий `test` не задан.
