# Демонстрационный маяк (`beacon`)

Клиентский визуальный модуль: светящееся кольцо. Зависит от `groundModule` и `simulationModule` через `requires`, высоту площадки получает через `deps.ground.heightAt`.

Публичное определение — `beaconModule` из `index.ts`. API экземпляра пустой.

Вращение и колебание вычисляются из `deps.simulation.snapshot().seconds` в существующем `onBeforeRenderObservable`. Не добавлять собственные часы или изменение симуляции ради анимации.

Категория в списке модулей: «Окружение».
