# Отрисовка объектов (`object-rendering`)

Функциональный клиентский модуль категории «Рендеринг». Публичное определение — `objectRenderingModule` из `index.ts`, зависимости — `geometryModule` и `objectTemplatesModule`. Зарегистрирован вне стартового набора; включение автоматически включает зависимости. Сам не регистрирует шаблоны, не размещает контент, не имеет панели и сценария ▶.

## API

- `createObject(templateId, name, parameters, ownerScope)` разрешает шаблон один раз и возвращает `{root, level()}`. `root` — Babylon `TransformNode` экземпляра, допускает положение, поворот, масштаб и родителя. `level()` — выбранный индекс LOD или `null` при скрытии/до первого кадра/после удаления. `name` — отладочное имя, не authority ID. Пустое имя, неизвестный шаблон, некорректные параметры и не представимые конечными границами размеры отклоняются до создания корня.
- `getDistanceOrigin(): DistancePoint | null` возвращает копию мировой точки отсчёта. По умолчанию это текущая активная камера; её view matrix обновляется перед чтением глобальной позиции. Если камеры нет — `null`.
- `setDistanceSource(read, ownerScope)` подключает единственный явный источник `() => DistancePoint | null`. Повторное подключение при активном источнике отклоняется. Scope снимает только своё подключение, после чего снова используется камера. Публичный тип `DistancePoint` — `{x,y,z}` с конечными числами.

В игре потребитель подключает отображаемую позицию управляемого героя, возвращая `null`, пока герой отсутствует. При `null` объекты скрыты, камера не подставляется. Неконечные координаты — явная ошибка. Модуль не импортирует управление игроком или игровой режим; отдельного `view-distance` нет. Публичных потребителей пока нет.

## Выбор представления

Одна подписка на `scene.onBeforeRenderObservable` обновляет все экземпляры перед отрисовкой; свой цикл/таймер не создаётся. В кадре точка отсчёта читается один раз. Вызов `createObject` не создаёт LOD-меши сразу: потребитель успевает задать преобразование до первого кадра.

Общая локальная AABB охватывает геометрию всех уровней шаблона, включая размеры, позиции и повороты деталей. Она вычисляется без создания мешей из прямоугольных деталей текущего `geometry`. Каждый кадр мировая AABB учитывает преобразование и родителя корня. Расстояние — евклидово до ближайшей точки мировой AABB, внутри неё — ноль. Поэтому смена уровня не меняет границу отсчёта, крупный объект не скрывается по расстоянию до центра. Мировая AABB может консервативно охватывать лишнее пространство при повороте составного объекта.

При `distance >= hideDistance` объект скрыт; на точном пороге уровня выбирается следующий. Ровно один целый составной LOD включён, остальные отключены. Кеш посещённых уровней создаётся лениво через `deps.geometry.createModel`; при повторном выборе уровень используется снова. Скрытие не выгружает ресурсы. Кеш живёт до удаления экземпляра; eviction и batching добавлять по замерам. Гистерезис и плавные переходы пока отсутствуют.

Картинка не меняет authority, коллизии, AI или события. Потребитель изменяет преобразование только корня, не геометрию внутренних уровней; иначе вычисленные по описанию границы перестанут соответствовать изображению. Перерегистрация ID шаблона не заменяет снимок существующего экземпляра: для обновления пересоздать его явно.

## Очистка и проверки

Корень немедленно регистрируется в scope потребителя. Корни созданных уровней связаны с его dispose; ранний `root.dispose()` удаляет экземпляр из списка обновлений, уничтожает все посещённые уровни, но не общую геометрию соседних объектов. Остановка модуля снимает подписку, очищает оставшиеся объекты и источник. Вызовы API после остановки отклоняются.

`tests/object-rendering.test.ts` использует только Node/NullEngine-фикстуры: точные границы нескольких уровней и исчезновения, повторное использование уровней, составные границы с поворотами/масштабом/родителем, мировую камеру и явный источник, отсутствие героя/камеры, ошибки координат и размеров, очистку. Никакого контента для FPS-замеров не добавлять. Браузерную проверку и производительность выполнять с реальным контентным потребителем, когда он появится.
