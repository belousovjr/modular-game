# River North: источник и адаптация

Источник: официальный репозиторий [City of Chicago — Street Center Lines](https://github.com/Chicago/osd-street-center-line), commit `ee45d118cec6760619568a5675278454d6324cf1`, файл `data/Transportation.geojson`. Это историческая версия, не актуальная дорожная навигация. SHA-256 исходного файла: `212bfb7e1adc160c66b80d791a2f5f4387dc2fbf1a934ed76b5db8f4f88a2904`. Выборка подготовлена 15 ноября 2026. Лицензия MIT, Copyright (c) 2013 City of Chicago; полный текст в [public/licenses/chicago-street-center-lines.txt](../../../../public/licenses/chicago-street-center-lines.txt), поставляется и с production build.

`river-north-source.geojson` — 234 исходных отрезка с OBJECTID, названием, типом и координатами, отобранные из фиксированной версии. Выбор: хотя бы одна вершина внутри longitude (−87.639, −87.626), latitude (41.8915, 41.9015), только явно перечисленные улицы. Полный файл города в игру не включён.

`river-north.json` — 23 упрощённых коридора для генератора. Локальная проекция: X направлен на восток, Z на север, начало (−87.6333°, 41.896°); X = Δlongitude × 111320 × cos(latitude₀), Z = Δlatitude × 111320. Одна единица = один метр. Поперечная координата улицы — медиана координат исходных вершин, округлённая до метра. Это местная приближённая проекция, не кадастровая точность. Кривизна улиц выпрямлена по осям. Неполные улицы Sedgwick/Franklin/Institute/Locust/Pearson/Delaware/Walton обрезаны по именованным пересечениям. Длины остальных коридоров ограничены границами адаптации.

Ширины 6/24 м, тротуары 2/4 м, плоскость с уклоном 1.5%, высоты/форма зданий и авторская площадь — игровые решения, не измерения из источника. Русло реки, эстакады, точные контуры зданий, интерьеры, направление движения и коллизии не воспроизводятся. Район — игровая адаптация улиц River North, а не цифровая копия.

Воспроизведение без сетевого доступа во время игры:

```sh
# Сначала получить исходник из указанного commit, вне запуска приложения.
node --max-old-space-size=128 scripts/prepare-river-north.mjs /path/to/Transportation.geojson
```

Скрипт проверяет SHA-256 и наличие выбранных улиц, читает GeoJSON построчно, сохраняет только выборку и схему. Runtime импортирует только маленький `river-north.json`; исходная выборка служит проверяемым происхождением данных и в JS bundle не импортируется.
