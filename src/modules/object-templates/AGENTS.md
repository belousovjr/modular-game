# Шаблоны объектов (`object-templates`)

Функциональный клиентский модуль категории «Рендеринг». Публичное определение — `objectTemplatesModule` из `index.ts`, единственная зависимость — `geometryModule` через `deps.geometry`. Зарегистрирован вне стартового набора. Каталог изначально пуст: реальные определения регистрируют потребители. Нет собственного контента, панели и сценария ▶.

## API и данные

- `register(definition: ObjectTemplate, ownerScope): void` — регистрирует один активный шаблон с данным ID. Пустой ID, повтор ID и версия, не являющаяся положительным safe integer, отклоняются. Версия описывает контент, не механизм версий программных модулей. Определение проверяется с параметрами по умолчанию перед регистрацией.
- `list()` — возвращает новые записи `{id, version}` в порядке регистрации.
- `resolve(templateId, parameters = {}): ResolvedTemplate` — применяет значения по умолчанию и проверяет разрешённые параметры, строит и проверяет все уровни. Не создаёт меши. Результат содержит `templateId`, `version`, параметры, `hideDistance` и `levels: [{distance, parts}]`; он JSON-совместим и не содержит функций/Babylon-ссылок. Детали и их массивы преобразований копируются, наружу не отдаются массивы рецепта.
- `createModel(templateId, name, parameters, ownerScope, level = 0)` — разрешает шаблон и создаёт только явно выбранный уровень через `geometry`. Возвращает `{template, model}`. Индекс должен быть целым и находиться в диапазоне. Положение/поворот/масштаб экземпляра задаются через `model.root`. `name` — отладочное имя, не authority ID.

Экспортируемые типы: `NumberParameter`, `TemplateLevel`, `TemplateContent`, `ObjectTemplate`, `ResolvedTemplate`. Потребитель `resolve` — `object-rendering`, который хранит описание экземпляра и автоматически выбирает уровень. `world` регистрирует определения контента через `register`.

Параметры пока только числовые: `{default, min, max}`, все числа конечные, `min <= default <= max`. Границы включительны, неизвестные ключи и выход за диапазон отклоняются; дробные значения разрешены. Строковые варианты и другие типы добавить по конкретной задаче контента, не строить универсальную схему заранее.

`build(parameters)` — доверенный синхронный чистый клиентский рецепт: возвращает описание, не создаёт Babylon-ресурсы, не читает время и не использует неуправляемую случайность. Параметры заморожены; настройки параметров копируются и замораживаются при регистрации. Функция остаётся клиентской реализацией и не передаётся authority или по сети. Для будущих игровых размеров нужны отдельные headless-правила, а не импорт этого клиентского модуля на сервер.

Минимум один уровень, первый порог — 0; следующие конечные пороги строго возрастают. `hideDistance` положительный, конечный и больше последнего порога. Геометрия каждого уровня проверяется через `deps.geometry.validateParts` перед созданием мешей; неподходящая конфигурация, прошедшая диапазоны параметров, также отклоняется. Число уровней не фиксировано.

Автоматического выбора LOD, вычисления расстояний, скрытия по дальности, материалов, коллизий и размещения мира здесь нет. Эти метаданные пока не меняют отображение самостоятельно. Не создавать все уровни в сцене ради хранения описания.

## Жизненный цикл и проверки

Регистрация сразу связывается с `ownerScope`; его очистка снимает только эту регистрацию, не более новую запись с тем же ID. Снятие регистрации запрещает дальнейшее разрешение ID, но не уничтожает уже созданные экземпляры. Модели принадлежат переданному в `createModel` scope, общие ресурсы — модулю `geometry`. Остановка модуля очищает каталог и запрещает вызовы API; зависимые модули останавливаются до него. Внешние переменные/ресурсы рецепта — ответственность регистрирующего модуля.

`tests/object-templates.test.ts`: тестовые здание с высотой и столб существуют только как фикстуры Node/NullEngine. Проверяются значения по умолчанию и диапазоны, JSON-описания всех уровней, независимые экземпляры с общей геометрией, ошибки до выделения ресурсов, границы версий/LOD, копирование описаний, снятие регистраций и остановка. Никакой искусственный контент для FPS-прогона не добавлять.
