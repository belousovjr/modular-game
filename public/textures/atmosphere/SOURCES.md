# Chicago backdrop and lunar texture

- Chicago: [USGS Imagery Only, The National Map](https://basemap.nationalmap.gov/arcgis/rest/services/USGSImageryOnly/MapServer), exported at 1024², 18 km square in local ground metres around -87.63075 / 41.88425. Service combines public-domain USGS/USDA NAIP orthophotography; [USGS NAIP public-domain description](https://imagery.nationalmap.gov/arcgis/rest/services/USGSNAIPImagery/ImageServer). This is aerial orthoimagery, not an invented satellite panorama. It is used as a georeferenced distant backdrop, not surveyed terrain/interactive buildings. The exact export query and output SHA-256 are in manifest.json. White missing lake tiles are extended from the last valid lake colour in that row; no extra buildings are fabricated.
- Moon: [NASA Scientific Visualization Studio CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/), LRO LROC colour map, NASA/GSFC/Arizona State University, public-domain data. Official 1024×512 JPEG reduced to 512×256 WebP. The official public HTTP download was used because the HTTPS endpoint did not supply a verifiable certificate chain in this environment. No accounts/credentials used. Exact source URL/hash in manifest.json.

Both images are pinned locally; no map requests, API keys or tile streams at runtime. Rebuild with `node scripts/prepare-atmosphere.mjs <input-directory>` containing chicago.jpg, moon.jpg and query.txt. The sky gradient and solar/lunar discs are unlit/emissive; no normal/AO map is claimed for the sky. Existing material albedo/AO/normals and real shadows remain separate.
